# Philippine dialect and tribe dropdowns

Source: Philippine Statistics Authority, [Ethnicity and Language/Dialect Generally Spoken at Home](https://psa.gov.ph/node/120299).

The 182 code/name pairs in `philippine-culture.json` were extracted from the PSA's 2010 Census of Population and Housing combined code list, published July 1, 2017, and accessed October 6, 2026. This is a historical census classification, not a claim of a complete contemporary language inventory or a list restricted to indigenous tribes. The Tribe field uses ethnic-group categories. Language and ethnicity remain independent selections; one is never inferred from the other.

Source code/name pairs are unchanged. UI adaptations: code 086 displays and saves Isnag for Dialect and Isneg for Tribe, while retaining the source aliases in the option label; codes 180–182 receive field-specific labels. Existing saved values are preserved. The app's existing text columns store selected names, not PSA codes.
